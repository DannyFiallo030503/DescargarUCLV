# Correcciones de contenido de las vistas previas

La auditoría del 2026-11-02 confirmó que `INDICE_UCLV_2026-10-28` contiene **30,058 directorios y no lista archivos**. Se quitaron los contadores que lo presentaban como “30 mil entradas”. La vista de búsqueda indica que usa datos de ejemplo y que falta sincronizar el catálogo.

Las cifras de selección/tamaño y espacio siguen siendo ilustrativas. En la interfaz funcional deben reemplazarse por datos medidos; si el runtime no puede consultar el disco, se muestra “espacio no disponible”. Las rutas y cantidades de las temporadas son ejemplos de estructura y no se presentan como sincronización completa.
