# Descargar UCLV 0.1.3 (pre-release)

Esta versión preliminar reúne la aplicación Android y la aplicación de escritorio Linux.

## Android

- APK de desarrollo: `Descargar-UCLV-0.1.3-debug.apk`
- Catálogo local, vista previa de medios y cola de descargas del cliente nativo.
- Pendiente validar en un dispositivo la descarga completa, pausa e interrupción/reanudación.

## Linux

- Paquete Debian amd64: `uclv-media_0.1.3_amd64.deb`
- App de escritorio con conexión directa desde la computadora al servidor UCLV.

## Limitaciones conocidas

- El navegador web no puede leer los listados de UCLV mientras el origen no permita CORS. Android y Linux realizan la conexión desde el propio dispositivo.
- El APK es una compilación debug, no un paquete Android firmado para publicación en una tienda.
- La reanudación necesita validación de transferencia en dispositivo con la conexión real.
